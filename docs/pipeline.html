LLM-driven data cleaning error detection, with optional adaptive Good-Turing / Chao1 false-negative estimation.

Overview

The pipeline takes a folder of curated CSVs, asks an LLM one question per (chunk × error type), clusters the findings deterministically by (source, row), and optionally synthesises each multi-type cluster into a canonical explanation. In adaptive mode it repeats the whole detection pass under small perturbations (row/column shuffle and/or prompt rewrites) and uses Good-Turing + Chao1 to estimate how many defects remain undiscovered.

Input data/curated/*.csv (≥ 4 cols, no empties; produced by src/data_prep/curate.py).
Detector one LLM call per (chunk × error type), in parallel, Azure round-robin endpoints.
Aggregator Phase A clusters by (source, row); Phase B synthesises multi-type clusters.
Loop up to K perturbed passes; stop when Good-Turing missing mass ≤ target.

① End-to-end flow

Control flow, orchestrated by experiments/run_cleaning_detection.py::main(). Two loops: the outer adaptive Good-Turing loop, and the inner per-chunk fanout (next section).

② One detection pass (inner loop)

Per pass the source frame is sliced into chunks, and for every (chunk × error type) pair one LLM call runs asynchronously. Results are parsed, tagged, and enriched with the source row context before feeding Phase A / B.

④ Key knobs in config/experiment.yaml

KeyEffect
experiment.modesingle = one pass, no GT. adaptive = perturbed multi-pass loop with GT early-stop.
data.chunk_sizeRows per LLM call. Keep it ≥ 100 so the model sees the full column distribution at once.
data.column_modesingle (one column per call) or all (full row). Cross-column error types require all.
prompts.error_types_fileTaxonomy YAML (_core, _simple, or fine-grained).
prompts.error_typesOptional subset of the taxonomy to actually run.
good_turing.num_runs, min_runs, target_missing_massControl the adaptive loop: hard ceiling, warm-up, and early-stop threshold.
good_turing.prompt_ensembleLLM rewrites each error-type prompt per pass — the primary perturbation source for cell-local types.
good_turing.shuffle_rows / shuffle_columnsFrame-order perturbation; additive with prompt_ensemble.
llm.enable_synthesisToggle Phase B (per-cluster LLM synthesis). Off → deterministic clusters only.
